About Local ASR

Local ASR Voice Studio

Version 0.1.3

Local ASR is an intelligent, high-performance offline speech recognition and typing assistant powered by Qwen3-ASR and Qwen2.5, featuring Continual LoRA Fine-Tuning, inverse text normalization, and real-time translation.
