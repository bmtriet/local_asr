Product Changelog & Updates

Version release history and new feature highlights for Local ASR

Version 0.1.3 - AI Summarize, Provider Switching & Dockerization

Latest
September 5, 2026
  • ✨
    AI Summarize & Executive Polish (Shortcut [S])

    New executive polish feature accessible on-the-fly during voice typing with shortcut S. Formulates concise bullet summaries, trims spoken filler words, and strictly preserves the user's spoken language.

  • ⚡
    Flexible Provider Switching (Localhost vs Remote API)

    Support for toggling between local embedded models and external OpenAI-compatible endpoints (Ollama, vLLM) for both ASR and translation/grammar directly in Settings.

  • 🐳
    Standalone Docker Container for Qwen3-ASR

    Packaged standalone container in docker/ exposing an OpenAI-compatible Whisper endpoint for deployment across servers and edge nodes.

  • 🏷️
    Custom Vocabulary & Keyword Mapping Visual Tags

    Transformed raw tables into modern visual badge tags with 50-item pagination and instant real-time search filtering.

  • 🛡️
    Reasoning Monologue Loop Fix

    Fixed internal thinking token exhaustion loops on Qwen 3.5 reasoning models, ensuring sub-1.5s response times without reasoning leaks.

Version 0.1.2 - Profile Management & Engine Stability

September 5, 2026
  • ✏️
    Profile Rename & In-App Customization

    Introduced a dedicated profile editing modal and backend API endpoint (PUT /api/profiles/{id}) to rename display names and update descriptions directly within the Web Studio interface.

  • 🛡️
    LoRA Adapter Unload Stability

    Added safe adapter unloading mechanism (unload_lora_adapter) when switching to profiles that do not yet have fine-tuned LoRA weights, preventing runtime crashes.

  • 🌍
    Complete English Documentation

    Comprehensive English translation of README.md encompassing setup guides for Linux, macOS, and Windows 1-Click/manual installations.

Version 0.1.1 - Clipboard Protection & UX Polish

September 4, 2026
  • 📋
    User Clipboard Data Preservation

    Automatically backs up the user's existing clipboard contents before simulated paste injection and restores it 100% untouched afterwards (Linux X11, macOS, and Windows). You will never lose previously copied text.

  • 🔗
    "About & GitHub" Author & Source Navigation

    Added an intuitive System Tray menu item and a Web UI header "About" button directing to the official repository by Triet Bui: github.com/bmtriet/local_asr.

  • 🔍
    System Tray Idle Icon Enlarged (~100%)

    Doubled the diameter of the idle microphone badge for sharp visibility on high-resolution system taskbars while retaining smooth pulsing animations during recording.

  • 🛠️
    Application Restart Mechanism Re-engineered (Restart App Fix)

    Replaced fragile in-process exec calls with clean detached subprocess spawning and clean exit, eliminating system freezes and socket conflicts when restarting the service.

Version 0.1.0 - The Genesis & UX Enhancement

Milestone
September 4, 2026
  • ✨
    Audio Feedback Cues (Synthetic Sound Effects)

    Plays subtle, elegant sine wave chimes upon starting recording, typing completion, and an alert sound on cancellation (ESC). Generates tones on the fly via SoundDevice with zero disk dependencies.

  • 📊
    Real-Time Audio VU Meter on OSD

    Added a dynamic microphone decibel level gauge right below the OSD status header, transitioning dynamically from cyan to emerald to confirm active microphone pickup.

  • ⚡
    Push-to-Talk (Hold-to-Talk) Mode

    Supports both activation models: Toggle Mode (press once to start, press again to stop) and Hold-to-Talk (hold shortcut down to speak, release to type immediately).

  • 🎙️
    Auto-Stop on Silence (Silence VAD)

    Integrated Voice Activity Detection (VAD) automatically detects pauses in speech and triggers transcription without needing a manual shortcut press.

  • 🚀
    Zero-Latency Audio Recording

    Microphone audio stream captures from the very first millisecond of hotkey activation, preventing missing or truncated syllables at the start of utterances.

  • 🔢
    Vietnamese Inverse Text Normalization (ITN)

    Automatically converts spoken numbers (phone numbers, OTP codes, date/time, credit card numbers) into clean, standard digits in < 0.001s.

  • 🌐
    OSD Language Selection & Bilingual Translation

    Fast translation routing to English [E], Traditional Chinese [Z], or press space to preserve original speech. Includes optional two-line bilingual output.

  • 🎯
    Continual LoRA Fine-Tuning & Hotwords Context Biasing

    Automatically learns from reviewed phrases and fine-tunes custom LoRA adapters on local GPU hardware without needing cloud connections.
